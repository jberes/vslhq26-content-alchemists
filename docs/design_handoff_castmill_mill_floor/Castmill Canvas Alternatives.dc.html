Castmill · §1.3.2 Campaign Canvas · mid-fi

Three navigation models for the centerpiece

Same campaign in all three: a 58-minute webinar fanned out into 14 artifacts across 7 channels. What varies is the spatial metaphor and the navigation model — free canvas, multi-pane desk, or a single vertical run sheet — because that choice decides how provenance, review state and scheduling can be shown at all.

Rendered in the Industry system attached to this project (steel-blue wireframe, Barlow Condensed) rather than the roadmap's warm ivory/terracotta sheet — the structure is what's up for decision here, and the token sheet can be swapped underneath any of them in an afternoon. Say the word and I'll re-skin the winner in Castmill's own palette.

Status ring is a left bar: draft · in review · queued · published

2Answering both questions about 1a

Where's the list of videos? There isn't one on this screen — a campaign is exactly one source. The list of campaigns lives one level up on the Front Page (and in ⌘K). 2a makes that explicit with a trail and a labelled source column. What are the lines? Provenance threads: every generated artifact stores the transcript segment IDs it was written from, so the line is literally "this card came from these words." 2b is the same idea without any lines at all, in case the threads are more clever than clear.

Reading this screen
① One campaign, one page. The list of sources/campaigns is the Front Page, one level up. ⌘K jumps between them without going back.
② The source column is a single video with its timed transcript underneath the player. Scrubbing the player scrolls the transcript.
③ The lines are provenance. Each generator returns the transcript segment IDs it drew from, stored with the artifact. Hover or click a card and Castmill draws a thread back to those exact segments — the highlighted rows — and labels them (s02, s05…). It answers "where did this sentence come from?" without opening anything.
If threads feel like decoration rather than proof, 2b drops them entirely.
2bNo lines — click a card and the source it quoted appears beside it, verbatim. Provenance as a citation panel, not a diagram.
