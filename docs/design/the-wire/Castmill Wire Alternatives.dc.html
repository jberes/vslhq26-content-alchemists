Castmill · §1.3.5 The Wire · replacing the week grid

Three ways to schedule that don't break

What's wrong with the grid you sent isn't styling — it's the model. Five equal day columns give every day the same 20% of the width whether it holds four posts or none, so titles wrap one word per line, action buttons land on top of the text, and 80% of the screen is empty ruled paper. A week has ~10 posts in it; a 5-column full-height grid is sized for 200.

All three below fix the same three things: titles get real width and clamp to two lines, actions live in a fixed column instead of inline, and days size to their content. Drag a queue item onto a slot in any of them.

Left bar: draft · queued · sent · error

2Run of Show — the other views it needs

Three more views, each answering a question 1a can't. Not skins — different axes. The range switch in 1a's header (Week / Fortnight / Month) covers 2a; 2b and 2c want their own switch next to it: By day · By channel · Sent. Everything keeps 1a's rules — rows size to content, titles clamp, actions in a fixed column.

2aMonth — cadence. Past ~10 days the time ruler stops being legible, and the question changes from "what time" to "are there gaps". So the month drops time entirely: one cell per day, count plus status bars. Ship this as the Month position of the range switch.
